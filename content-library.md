## 📊 CONTENT LIBRARY USAGE GUIDE

### How to Use This Library

**Every week, pick 3 topics from any cluster:**
- 1 from Maxwell Laws (Cluster 1)
- 1 from Personal Narrative (Cluster 2)
- 1 from Community/Lifestyle (Cluster 3)

**For each topic:**
1. Pick the gaya that fits best (or rotate)
2. Choose primary platform (IG/TikTok/LinkedIn)
3. Adapt copy using provided starter
4. Source visual (stock image, personal photo, video)
5. Tag in Notion database with:
   - Topic ID
   - Content Gaya
   - Platform (Primary + Secondary)
   - Status (Draft → Scheduled → Posted)

### Platform-Specific Lengths

| Platform | Gaya 1 (Story) | Gaya 2 (Education) | Gaya 3 (Community) |
|----------|---|---|---|
| **IG Reels** | 30-45s | 45-90s | 30-45s |
| **IG Carousel** | N/A | 5-7 slides | 5-7 slides |
| **TikTok** | 30-60s | 45-90s | 30-45s |
| **LinkedIn** | N/A (post + comment) | Article (500-1000w) + Post | Post + comment |

### Weekly Workflow (3x/minggu)

**Monday:** Pick topic + write Gaya 1 (Storytelling) → post to IG Reels
**Wednesday:** Pick topic + write Gaya 2 (Educational) → schedule to TikTok + IG Carousel
**Friday:** Pick topic + write Gaya 3 (Community) → post to LinkedIn + IG Stories
