## CONTENT FORMULA (Template)

### Reels IG Template
```
Hook (0-3 detik): Pertanyaan / klaim kontroversial
Bridge (3-10 detik): "Tapi sebelum itu..."
Body (10-45 detik): Isi konten (3 poin)
CTA (45-60 detik): "Follow @growwithika_ / Link in bio"
```

### TikTok Template
```
0-3 detik: Hook visual + text overlay
3-15 detik: Konten utama (fast paced)
15-20 detik: CTA + follow
```

### LinkedIn Post Template
```
Headline: [Hook] + emoji
Paragraf 1: Context/personal story
Paragraf 2: Nilai / pelajaran
Paragraf 3: Call to action (comment / DM)
Hashtags: #Kepemimpinan #IbuTangguh #KomunitasTumbuhBersama
```
